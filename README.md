## What This Actually Does

Most GIS portfolios show maps.
This one shows **how decisions are made from data**.

* Identify hotspots and risk zones
* Build location-based dashboards
* Transform raw datasets into structured insights
* Deliver outputs that can actually be used (not just screenshots)

---

## System Overview

Instead of random tools, this project follows a structured pipeline:

Input → Processing → Storage → Output

* Input: CSV, spatial datasets
* Processing: Python, QGIS
* Storage: SQLite / SQL
* Output: Maps, dashboards, reports

Everything is designed to reduce manual work and increase clarity.
